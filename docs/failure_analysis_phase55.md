# Phase 55 失败案例与修复

案例和原始现象保存在 `docs/failure_cases_phase55.json`，由 `/api/evaluation/summary` 在评测页展示。

1. “销售数量最多的音乐类型是什么？”原先落入单表；第一轮只加路由词后，真实调用仍因 Schema Linking 无法关联而失败。随后在真实 Schema 别名、业务关键词和关联触发词中补齐“销售数量”，并防止宽泛的“销售”错误召回订单金额。真实 Chinook 复测得到 Rock、835，SQL 通过真实外键连接 `genre → track → invoiceline` 并汇总 `Quantity`。回归测试覆盖路由和 Schema Linking。
2. 在跨源页面明确选“不使用 PDF”时，前端原先发送 `null`，后端会自动选知识库唯一的 PDF。现在前端发送空字符串，后端明确提示选择 PDF；`null` 继续保留旧 API 的单文档自动选择兼容行为。回归测试覆盖工具与 Agent 答案。
3. 首次 PDF 问答一次实测约 89.6 秒，热态约 1.263 秒。尚未定位模型加载的具体瓶颈，也没有设置可证明有效的预热方案，保持为待处理问题。

修复后统一自动化回归 518/518 通过，前端构建通过。上述结果只覆盖本机现有数据和测试集。
