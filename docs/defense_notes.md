# 答辩讲稿提纲

> **数字口径提示**：本文为讲稿提纲，其中的回归条数与历史正确率保留不改写；对外引用一律以 `docs/metrics.json` 指标真值表为唯一来源（见其中 C1–C6 冲突处置）。稳定版严格行比对口径与实验分支口径不得混用。

## 3 分钟

问题：数据库与 PDF 分离，传统演示容易给出无依据答案。方案：Vue 前端接 FastAPI，原有 SQL 与 RAG 服务由有限步骤 Agent 串联。创新点：真实外键约束 JOIN，跨源中间值需要核实，证据与 Trace 可点开。Demo：先问美国客户 13，再用合成 PDF 的阈值 5 查询发票超过阈值 179，并展示 SQL 与第 1 页引用。数据结果：本机 518 条回归全通过，历史 V3 50 题结果正确率 76%。总结：当前能演示可解释的单/双源回答，未知文档与冷启动性能仍有边界。

## 5 分钟

在 3 分钟版基础上增加：解释语义标准化 → Schema Linking → 外键路径 → 只读 SQL；PDF 扫描页才 OCR，复杂度决定切片策略；演示 Rock 销量 835，并在 PDF 中定位同名描述。指出回归断言与真实问答准确率不是同一个指标；展示 `/evaluation` 的来源和未测项目。

## 10 分钟

在 5 分钟版基础上增加：展示 5 张架构图、公式 120/100→20% 的安全计算、一次“这是什么意思？”澄清案例、一个不使用 PDF 时的明确提示。打开 Agent 详情查看 Router、Plan、Tool、Evidence、Trace 与耗时。再说明 3 个真实失败案例：销售数量词漏识别已修复、PDF 空选项已修复、首次模型加载慢仍待优化。最后按 `docs/deployment.md` 演示安装和健康检查，并用 `reports/test_summary.json` 核实测试数量。
