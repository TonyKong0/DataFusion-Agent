# V5 跨源演示用例

本页的问题用于展示路由、规划、证据和失败降级。选择的 PDF 必须确实包含相关内容；如果上传的是《岳阳楼记》，审核阈值和音乐类型的问题应明确返回“关联未核实”，不应编造答案。

跨源智能体的关键区别是**第二步使用第一步的结果**。页面的“跨源关联”卡片有三种情况：

- 已核实关联：文档数值进入 SQL 的比较条件，或数据库查出的名称出现在引用的 PDF 原文中；卡片链接到两边证据。
- 关联未核实：虽然调用了两边工具，但没有证据证明中间值被正确使用；不得给出跨源结论。
- 并列取证：两个独立问题分别查询，结果可以并列展示，但不算跨源推理。

要现场演示成功关联，请上传与 Chinook 数据相关的 PDF。例如一页 PDF 明确写有“单笔金额审核阈值为 5 元”，再问“文档规定的单笔金额阈值是多少，数据库里有多少发票超过这个值？”。核对卡片中的阈值、原文页码及 SQL `WHERE` 条件。金额单位和数据库字段单位必须由演示资料明确说明；否则只展示查询过程，不应宣称业务口径完全一致。

## 文档 → 数据库

示例：`文档规定的审核阈值是多少，数据库里有多少订单超过这个值？`

预期流程：`document_search → 提取带页码的数值 → database_query → SELECT-only SQL → 双源证据`。需要上传确实写有阈值的 PDF；Chinook 的 Invoice 是发票数据，问题中的“订单”需由现有语义层解释。

## 数据库 → 文档

示例：`数据库中销量最高的音乐类型是什么，文档里如何描述它？`

预期流程：`database_query → 取查询结果 → document_search → 双源证据`。文档没有描述该类型时，应保留数据库部分结果并标明文档缺失。

## 并行取证

示例：`数据库里有多少客户，文档里记录了多少？`

两个工具均被调用；这两个数值代表的统计口径如果不同，不应直接当作同一个事实进行冲突判定。

## 公式

示例：`根据文档中的公式计算数据库销售额增长率？`

此功能需要指定具体文档公式。只有数据库返回唯一一行、数值列名与文档公式变量名逐一匹配时，系统才调用 V4 安全计算器代入，并同时保留公式页码与 SQL；否则返回参数无法确定，不会把文档原有计算结果冒充数据库计算结果。

## 澄清和失败降级

`这是什么意思？` 应要求用户说明数据源。文档无索引、检索超时或缺少可引用片段时，应展示已成功的 SQL 结果，并说明无法完成完整跨源结论。
