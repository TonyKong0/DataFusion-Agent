# DataFusion Agent V1.0 · 基础版本收尾

收尾日期：2026-09-29。版本定位是赛题基础 40 分 Demo，覆盖 [Phase 0–10](phases/README.md)；后续能力不包含在本版。

## 已交付

| 模块 | V1.0 结果 |
| --- | --- |
| 前端 | 保留 Vue 3 + Vite + JavaScript 原工程；Vue Router 提供 `/`、`/data-agent`、`/data-agent/document`；问答、SQL、结果表、引用、Trace 可交互展示 |
| NL2SQL | Chinook MySQL 实时 Schema、DeepSeek 生成单表 SQL、SQLGlot 只读校验、只读执行和中文回答 |
| RAG | 单份文本 PDF 上传、按页解析和切片、BGE-M3 向量化、FAISS 检索、DeepSeek 基于命中片段回答及来源页预览 |
| 可解释性 | Generated SQL、Query Result、Sources、Execution Trace |
| 测试 | 至少 10 条 NL2SQL 与 10 条 RAG 真实用例；后端单元测试与前端构建检查 |

后续增补的顶部模式路由、浏览器本地历史会话、单条会话删除和 PDF 原页预览已纳入 V1.0。仍只支持单表、单份可提取文字的 PDF；不包含多表 JOIN、OCR、自动意图路由或复杂 Agent。

## 目录与依赖

- `src/` 是前端源码；`backend/app/` 是后端源码；`database/` 是 Chinook 数据；`docs/` 是项目文档。
- 阶段记录统一放在 `docs/phases/`，界面验收和截图统一放在 `docs/ui/`。原 Vue/Vite 未使用的示例组件和素材已从源码目录移除。
- `backend/requirements.txt` 保留运行依赖；`backend/requirements-dev.txt` 在其基础上增加固定版本的 pytest。前端依赖由 `package-lock.json` 锁定。
- `backend/.env`、`backend/data/`、虚拟环境、`node_modules/`、构建产物和测试缓存均由 `.gitignore` 排除；Gitee 克隆后须按 [使用说明](../使用说明.md) 准备本机配置和模型。

此记录是本地 V1.0 验收，不代表已经创建 Git 标签或推送到远程仓库。
