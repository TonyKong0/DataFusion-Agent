# Phase 54 性能记录

2026-10-07，在本机 Windows、Chinook MySQL、DeepSeek 与 BGE-M3 环境测量。这里的数字是实际请求样本，不作为通用性能承诺。

| 路径 | 改动前样本 | 改动后样本 | 说明 |
| --- | ---: | ---: | --- |
| 单表 NL2SQL | 约 2700 ms | 未作同路径复测 | 前后不是同一接口，不能推断加速比 |
| 跨源 Agent | 3942 ms | 未作同问题复测 | 该问题需要数据库和文档两个工具 |
| 文档 RAG | 首次约 89600 ms；热态 1263 ms | 未改模型加载策略 | 首次时间包括 BGE-M3 模型初始化，不应和热态直接比较 |
| Agent 单表问题 | 未记录同问题基线 | 3425 ms | 路由 17 ms、数据库工具 3406 ms、语义 10 ms、Schema 55 ms、SQL 1524 ms、LLM 2 次 |

本阶段保持既有规则路由和进程内 Schema 缓存，避免简单问题被强制送入多工具 Planner。优化点是纯数据库请求不再枚举 PDF 文档索引。Agent 响应的 `latency` 新增数据库、检索、公式及数据库内部语义、Schema、SQL 阶段的实测毫秒数。嵌套阶段属于工具耗时的子集，不能和总时长直接相加。

当前没有同问题、同环境的充分前后样本，因此不声称已量化提速。下一轮优先处理首次文档检索的模型加载耗时，并继续记录冷、热态分别的分位数。
